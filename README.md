# quote-netzip-fullpull-replication skill

Shared agent governance skill for `netzip-fullpull` and its Rust consumers.

Install the directory as `quote-netzip-fullpull-replication` in the supported
agent's user skill root. The skill resolves the crate through Cargo path
dependencies, so it works with native, Samba, and SSHFS workspace paths.

Protocol facts remain in the `netzip-fullpull` repository's `docs/` directory;
this repository contains workflow and ownership rules only.
